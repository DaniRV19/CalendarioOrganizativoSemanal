# 📅 Calendario Organizativo Semanal

Aplicación web para la **organización y planificación semanal de eventos**, permitiendo gestionar fácilmente las actividades según el día, horario y duración.

## ✨ Funcionalidades

- 📆 Visualización de un calendario semanal.
- ➕ Creación de eventos seleccionando día y rango horario.
- 🎨 Personalización del color de cada evento.
- ✏️ Gestión y modificación de eventos.
- 🗑️ Eliminación de eventos.
- 📄 Exportación y descarga del calendario en formato PDF.
- 🕐 Organización de eventos mediante intervalos de tiempo.

## 🛠️ Tecnologías

`HTML` · `CSS` · `JavaScript`

## 🚀 Objetivo

Proyecto desarrollado para crear una herramienta sencilla e intuitiva que facilite la **planificación y organización de actividades semanales**, centralizando los eventos en una interfaz visual y permitiendo exportar el calendario para su uso fuera de la aplicación.
